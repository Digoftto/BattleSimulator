# PROJECT_STATUS.md
## Estado Atual do Projeto — Battle Simulator

Status: CANÔNICO

Objetivo deste documento:
Este arquivo NÃO descreve o jogo.

Ele existe para informar qualquer IA, colaborador ou futuro membro da equipe sobre o estado atual da documentação do projeto, evitando a criação de documentos redundantes, sistemas já resolvidos ou alterações em decisões já congeladas.

---

# 1. Filosofia de Trabalho

O Battle Simulator utiliza documentação modular.

Entretanto, a modularidade NÃO significa criar o maior número possível de documentos.

Sempre que dois assuntos são consultados pela mesma pessoa durante a mesma etapa de desenvolvimento, eles devem permanecer no mesmo documento.

Criar novos documentos deve ser exceção.

Antes de sugerir um novo documento, verificar se o assunto já pode ser incorporado naturalmente a um documento existente.

# 4. Filosofia Geral já definida

As seguintes decisões são consideradas pilares do projeto.

Não sugerir alterações sem motivo forte.

• crescimento por adição;

• o Reino amadurece, nunca troca de identidade;

• os três Fundamentos são leis físicas do universo;

• as facções representam filosofias diferentes, não alinhamentos morais;

• cartas representam pelotões registrados;

• durante a batalha existem pelotões, não cartas;

• o comandante lidera pelotões pertencentes ao Reino;

• o jogador administra um Reino, não personagens;

• território representa identidade permanente;

• battlefield representa condições temporárias;

• arte deve comunicar função antes de ornamentação;

• reutilização possui prioridade sobre produção de assets exclusivos.

# 5. O que NÃO sugerir novamente

✘ criar documento para layout das cartas

✘ criar documento para iconografia

✘ criar documento para filosofia das facções

✘ criar documento para batalha

✘ criar documento para pelotões

✘ criar documento para construções

✘ separar documentos apenas porque ficaram grandes

✘ dividir documentos quando os assuntos pertencem à mesma etapa de produção.

# 7. Antes de sugerir um novo documento

Responder mentalmente:

1.
Esse assunto já está documentado?

2.
Existe algum documento onde ele se encaixa naturalmente?

3.
A criação de um novo arquivo realmente reduzirá retrabalho?

4.
Esse documento será consultado por vários anos?

Se qualquer resposta for negativa, preferir atualizar um documento existente.

---

# 8. Missão atual do projeto

O Battle Simulator encontra-se na fase de transição entre:

Fundação

↓

Produção

A prioridade não é mais inventar o universo.

É transformar a documentação existente em um jogo jogável.

# 9. Papel da IA neste projeto

A IA deve atuar prioritariamente como:

- diretor de design;
- revisor de consistência;
- apoio arquitetural;
- produtor de conteúdo;
- consultor artístico;
- consultor de gameplay.

Ela não deve assumir automaticamente que falta documentação.

Sempre verificar primeiro se o assunto já foi tratado nos documentos existentes.

Na dúvida, perguntar ao usuário antes de propor novos arquivos.
